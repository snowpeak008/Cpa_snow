CPA 账号代理快速绑定工具

打开方法
双击本目录的“启动绑定工具.cmd”。这是中文桌面窗口，不需要安装新依赖。
当前电脑使用 C:\Program Files\Python312 中的 Python/Tkinter，以及现有 SSH 密钥。
服务器为 root@104.160.39.169，默认代理类型 HTTP，默认端口 12323。

单个账号
1. 填写账号邮箱、代理 IP、端口、代理用户名和密码。
2. 如果批量列表为空，直接点“1. 预览绑定”。
3. 核对旧代理、新代理和账号状态，点“2. 确认绑定”。
也可以点“加入下方列表”，凑成多条后一起绑定。

多个账号
支持直接粘贴如下格式，按粘贴顺序逐个绑定：

alice@example.com
192.0.2.10:12323:代理用户名:代理密码

bob@example.com
192.0.2.11:12323:代理用户名:代理密码

以上是格式示例，不是真实代理。请替换成自己的账号和代理。

也支持每行一条：
alice@example.com 192.0.2.10:12323:代理用户名:代理密码
bob@example.com 192.0.2.11:12323:代理用户名:代理密码

如果多条代理用户名和密码相同，可填写上方通用用户名、密码，下方只写：
alice@example.com 192.0.2.10:12323
bob@example.com 192.0.2.11:12323

批量条目中已有的用户名、密码优先于上方通用设置。
支持完整 http://、https://、socks5://、socks5h:// 代理 URL。
IPv6 请使用完整 URL，例如 http://用户名:密码@[2001:db8::1]:12323。
完整 URL 中的用户名或密码若包含 @、/、#、% 等字符，请使用 URL 百分号编码；
通过独立表单或 IP:端口:用户名:密码 输入时，工具会自动编码。

它具体会做什么
- 只绑定已经存在于 CPA 的 Claude OAuth 账号；输入邮箱不会创建或登录 OAuth 账号。
- 预览只读取当前状态，不写入；未找到邮箱或同一邮箱匹配多个账号时不允许执行。
- 显示代理入口重复提示，便于发现多个账号共享同一入口；入口相同不一定代表出口相同。
- 执行前将原代理加密保存到 runs 子目录，保存成功才开始写入。
- 只通过管理接口修改 proxy_url，随后读取文件复核；不上传整个 OAuth 文件。
- 保留启用/停用状态，不重启 CPA，不修改全局配置、插件或 5/2 并发限制。
- “停用”仅表示 CPA 不调度账号，不是官方封禁结论。
- 相同代理会跳过写入。预览之后代理、账号身份、启用状态或服务配置变化，会停止并要求重新预览。
- 遇到错误或连接超时立即停止后续账号，不自动重试，也不自动回退已完成账号。
- 一批不是全有或全无的事务。部分完成时，上方结果和 report.json 会标明各账号状态。

出口查询
“绑定后查询出口 IP”默认关闭。
勾选后，每个已绑定账号只查询一次 api.ipify.org，使用 CPA 内存中该账号代理，记录实际出口。
查询不发送 OAuth token、不调用模型、不刷新额度。查询失败会停止后续账号，已写入绑定保留。
未勾选时，“已绑定”表示字段写入和读取核对成功，不代表代理可联网或 Claude 账号可用。
出口 IP 可以与代理入口 IP 不同，工具只记录实际出口，不将入口不同自动判定为失败。

如何回退
执行后点击“回退刚才这批”；关闭再打开后，用“选择历史记录回退…”选择 runs 中对应的 report.json。
工具恢复原 proxy_url，保留回退时账号的当前启用状态。
如果该账号代理后来已被其他操作改过，工具拒绝覆盖并停止回退。
如果原来未配置账号代理，则恢复为空字符串，重新继承原来的全局代理；不恢复“字段不存在”的字节形式。
回退只恢复代理字段，不恢复 OAuth token，不恢复历史启用状态，不需要重启。
断线后结果待核对时，可选择同一批记录回退：已是原代理的会跳过，仍是本批新代理的才会恢复。

记录和密码
所有脚本、使用说明、测试结果和回退记录都在本工具目录内。
runs/日期时间-批次号/report.json：不含密码的执行结果。
runs/日期时间-批次号/before.dpapi：Windows 当前用户加密的原代理信息，只含回退所需字段，不备份 OAuth token。
runs/日期时间-批次号/rollback-*.json：不含密码的回退结果。
回退备份一般只能在当前 Windows 电脑、当前用户下解密，请勿将它当成跨电脑迁移备份。
新代理密码不写入本地普通日志或脚本，按要求写入服务器账号 proxy_url；通过 SSH 标准输入传递。
批量粘贴区会显示你粘贴的文本，关闭工具后不会自动保存这些输入。独立密码框使用掩码。
不需要把管理密钥填写进工具；管理密钥仅由服务器端读取。

验证情况
离线测试包括批量格式、特殊字符、重复/缺失账号、5/2 限制保持、启用状态保持、
加密备份、错误停止、请求回包丢失后的回退、回退冲突保护、出口查询不带 OAuth，
以及 GUI 预览→绑定→回退的完整 mock 流程。
test-results.txt 为本机测试输出。
read-only-connection-check.json 为真实服务器只读连接验证，未执行任何生产写入、模型调用或出口查询。
本次工具制作没有重新绑定任何生产账号。实际写入流程沿用此前成功使用的管理接口。
