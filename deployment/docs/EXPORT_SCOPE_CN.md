# 导出范围与脱敏说明

本次只读核对生产镜像、配置结构、插件注册信息、静态文件和哈希。未停服务、未改配置、未改变账号状态、未发模型请求、未刷新额度。

## 保留

- CPA v8.0.31 镜像名称和实际 digest。
- 五个已启用动态插件的原始 Linux amd64 `.so`、版本、大小和 SHA256。
- 生产管理页面的原始 HTML 和 SHA256。
- v8.0.31 标签指向的干净源码，以及已发布插件源码和许可证。
- 与生产部署记录一致的 account-concurrency 1.2.1 源码与测试。
- 当前非敏感配置，包括 Key 5 / 账号 2、路由、冷却重试、请求日志关闭、插件优先级和数据目录。

## 移除或替换

- OAuth access/refresh/id token、账号 JSON、邮箱和账号索引、代理绑定。
- 客户端 API Key、管理密码及其原哈希、代理用户名密码、SSH 密钥。
- 额度记录、请求历史、SQLite 数据库及 WAL/SHM、日志、故障抓包、备份目录。
- 未部署的本地候选补丁、临时构建和离线测试夹具。
- 无关的 VPN、3x-ui、Nginx 和其他服务资料。
- 原全局代理替换为空；管理密钥、客户端 Key 改为占位符，由初始化脚本生成新值。
- 原 Compose 的绝对 env_file 路径改为本地 `.env` 注入管理密钥；宿主数据目录改为 `deploy/state/`。
- 无实际插件的 `example` 配置从可运行模板移除。
- 镜像从只指定 tag 改为 tag+digest；`pull_policy` 改为 `missing`，避免标签漂移。

## 证据边界

镜像 digest 与下载产物 SHA256 对应归档时的生产文件。上游核心源码确认属于 `v8.0.31`；第三方源码来自对应发布标签。未重新编译整个镜像和所有插件，因而不宣称源代码重建结果与发布产物逐字节一致。

自定义插件源文件与此前上线 1.2.1 时的构建来源逐项相同；此前通过的并发和会话恢复测试不等于本次重新运行生产模型测试。

管理页面保存的是已构建 HTML，不包含它完整的独立前端源码项目；记录其上游来源与许可证，生产实际页面以存档哈希为准。

空数据库意味着 API Key Manager 的历史额度、用量和管理数据不随仓库恢复。需要迁移运行数据时，应通过独立的私密备份流程进行，不要取消本仓库的忽略规则。
