# account-concurrency 1.2.1-session-recovery

此目录是当前已部署插件的源码，不是早期 1.2.0 候选。服务器的实际二进制保存在 `runtime/plugins/linux/amd64/account-concurrency.so`。

- 每 Key 并发默认 5，只接受配置 `max_per_key` 为 1–5；每账号固定 2。
- 会话绑定优先复用原账号，TTL 为 1 小时，最多 4096 条。
- 网络错误、429、5xx 只释放并发占用，保留会话偏好；不会仅凭 401/403 删除绑定。
- 原账号忙碌或临时不在候选中时借用其他可用账号，不更新原绑定。
- 宿主本地完整账号清单确认原账号已停用或移除时，才清除绑定；查询异常则保留。
- 没有可靠会话标识时继续原选号方式，不伪造 session；内存绑定不跨重启保存。
- 限额是单 CPA 进程内的限额，多副本不会共享计数。

构建来源环境为 Go 1.24.13、Debian 12、GCC 12.2、linux/amd64。原构建容器镜像：

`golang:1.24-bookworm@sha256:1a6d4452c65dea36aac2e2d606b01b4a029ec90cc1ae53890540ce6173ea77ac`

在隔离构建环境内将该目录挂载为 `/src` 后运行 `sh /src/build.sh`。构建会运行 race 测试并生成 `.so`，不要直接将未验收的新产物覆盖运行实例。
