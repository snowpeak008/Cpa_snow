Snow Console／雪峰控制台 — 可复制部署包
制作日期：2026-10-26；当前版本 A.0.2（仅更新 Git，未部署）

这是什么
这是当前 Docker + CPA 服务的“程序与脱敏配置”备份，不是服务器整盘镜像。
按你的选择，不含 OAuth 账号、API Key、管理密钥、代理凭证、SSH 私钥和用量数据库。
不含 3x-ui / Xray / VPN 的程序、配置或用户数据，也不包含历史排查目录和临时测试实例。
恢复时需要重新导入账号，并逐个设置代理；原账号启用状态和历史账本不在此包内。

三个核心文件（直接双击）
01-登录服务器.cmd
  打开交互式 SSH 终端，登录当前服务器。输入 exit 断开。
02-启动SSH通道.cmd
  后台建立本地 18317 → 服务器 8317 通道，并打开网页。
  重复双击不会重复创建同一通道；连接失败不会无限重试。
03-关闭SSH通道.cmd
  只关闭本套工具创建的通道，也兼容原项目旧通道启动器。
  不关闭其他 SSH 终端，不停止服务器上的 CPA。

上述 CMD 要与 ssh 文件夹一起保留，不能只把单个 CMD 拷出去。
当前电脑沿用已有 SSH 私钥和 known_hosts；没有把私钥塞进备份。
换服务器/换电脑时，修改 ssh/settings.json 中的地址、用户名、端口、私钥路径。
新服务器主机指纹需先通过可信的服务商控制台核对，并正常建立 SSH 信任；不禁用主机校验。
只打开后台通道需要现有密钥支持无交互认证。

新服务器复制部署
详细步骤见“新服务器部署与回退.txt”。
Docker 安装包锁定为当前 Ubuntu 22.04 amd64 版本。
CPA 镜像及五个插件按当前运行版本归档，支持离线导入；基础系统依赖可能仍需要联网安装。
完整流程是：准备新服务器 → 安装 Docker → 校验备份 → 导入镜像 → 初始化新密钥 → 启动服务 → 导入账号与代理。
请不要把新部署脚本用于当前服务器的第二套实例；脚本遇到同名容器、已有状态或端口占用会拒绝继续。

目录
deployment/     Docker 安装包、CPA 镜像、五个插件、脱敏配置、源码、许可证和部署脚本
ssh/            三个 CMD 的通道实现与连接参数
web/            Snow Console 可复现清理后模板及构建素材、本地演示、网页回退脚本
extras/         账号代理绑定工具、费用查询脚本；只含代码，不含输入记录和凭证
evidence/       哈希、来源、测试、脱敏检查及页面替换记录
tools/          本次采集/构建/验证脚本；部分采集入口依赖原项目，不是新服务器部署入口
archives/       可整体复制的 ZIP 备份包
